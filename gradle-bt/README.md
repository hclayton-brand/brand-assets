# Gradle Build Tool signature artwork

Awaiting artwork. Drop these three files here, using these exact names — the
generator references them by name, so no code change is needed once they land.

| Filename | What it is |
|---|---|
| `gradle_bt_icon_primary.png` | The mark alone. Renders at **52px** wide, so supply ~2–4x that (the Develocity equivalent is 726×705) to stay crisp on retina. |
| `gradle_bt_lockup_dark.png` | Full lockup, **dark** wordmark — for light mail backgrounds. |
| `gradle_bt_lockup_light.png` | Full lockup, **light** wordmark — for dark mail backgrounds. |

Both lockups must be the same artwork at the same pixel size; the dark-preview
toggle swaps between them and any mismatch makes the logo jump.
