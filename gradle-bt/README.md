Derived from `GBT_Logo@2x.png` (1884×491). The mark is a straight crop; the
light lockup has its ink inverted to white with the teal artwork untouched.

Brand teal, sampled from the elephant gradient: **`#38B3C2`**. The swoosh in
"develocity" is `#2CA7BE`, Develocity's own teal — correct in a co-brand lockup.

The two lockups are the same artwork at the same pixel size, so the generator's
dark-preview toggle can swap them without the logo shifting.
